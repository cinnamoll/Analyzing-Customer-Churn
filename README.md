# 📊 Customer Churn Analysis Case Study

This repository showcases my work from the **Customer Churn Analysis Case Study** completed as part of DataCamp's Excel Fundamentals Skill Track. The goal was to analyze customer churn trends and identify key factors contributing to customer retention and loss.

## 📁 Project Overview

In this case study, I used **Excel** and **Power BI** to:

- Clean and prepare data for analysis
- Visualize key metrics like churn rate by demographic and service usage
- Analyze patterns and trends to gain insights into churn drivers
- **Illustrate relationships between key variables** influencing customer churn

## 🔗 Extended Analysis with Spreadsheet & Power BI

To deepen the analysis, I integrated **spreadsheet modeling** and **Power BI dashboards** to explore the relationship between churn and multiple categorical variables:

### Variables Analyzed:
- **Age Group**
- **Data Plan** (unlimited vs. limited)
- **State (US)**
- **Competitor Offers** (presence of better promotions from rival providers)

### Key Visualizations & Techniques:

| Tool         | Purpose |
|--------------|---------|
| **Spreadsheet (Excel/Google Sheets)** | Pivot tables, conditional formatting, and correlation matrices to summarize churn rates across segments |
| **Power BI** | Interactive dashboards with slicers for age group, state, and competitor offers; scatter plots and bar charts to visualize churn drivers |

### Example Insights Uncovered:

- Customers in the **18–30 age group** with **limited data plans** are significantly more likely to churn when **competitor offers** are available in their state.
- **States with high competitor activity** (e.g., CA, TX, NY) show a **15–20% higher churn rate** among users without long-term contracts.
- **Unlimited data plan users** over age 45 have the **lowest churn rates**, especially in states with fewer competitor promotions.

## 📈 Key Insights (Updated)

Through data preparation, visualization, and multi-tool analysis, this case study uncovered:

- The **interaction between age, data plan, and competitor offers** is a stronger churn predictor than any single variable alone.
- **Geographic segmentation (by state)** reveals regional churn hotspots linked to external competition.
- Retention strategies should prioritize **young users with limited data plans** in highly competitive states.
